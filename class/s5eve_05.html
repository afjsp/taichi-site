第五堂課

2026.09.02
本堂內容

2026-09-02｜主題：五點放鬆串起單腳站立，以四元素把如封似閉打慢

一、本堂核心

這一堂從學員提問切入，先把「五點放鬆」講清楚，再把它接回單腳站立的四個要素。中段回到感覺練習的基本功，練的是在吐氣時看見肌肉自己放下來，而不是用力把它壓下來。後半段完整打了兩遍第一段拳架，並新教如封似閉。阿郎全堂反覆強調同一件事：先讓身體疏通，再談動作大小；先讓結構在，再談肌肉要鬆到哪裡。

二、五點放鬆與單腳站立的四個要素

五點指的是肩膀、膻中穴、髖關節、膝蓋、湧泉穴。做法是用手貼在點上，配合吸氣吐氣去感受那一點的肌肉變化，只要吐氣時抓到「力量卸下來」的感覺就算到位。膝蓋與湧泉穴不容易摸到，改用觀想，吐氣時想像那口氣從腳掌的湧泉穴洩出去。五個點都跑過一次之後，用一口吐氣從肩膀一路走到湧泉穴，讓上半身整條鬆下來、下盤紮實地撐著。

單腳站立需要四個要素同時在：一是三點一線，大拇指內側、膝蓋、髖關節要落在同一條線上，膝蓋往外或往內跑都容易翻車受傷；二是腳掌與地面的接觸要均勻，腳跟與前腳掌後方那排骨頭都要吃到力，不能只有一點凸起來；三是上半身透過五點放鬆往下沉；四是腿力。腿力靠重訓與深蹲，站樁最能調整第二與第三項，坐姿則是讓身體先知道「整個鬆下來」是什麼感覺。

三、感覺練習：把控制調小，把觀察放大

基本功一樣從三次深呼吸開始。手舉到肋骨下緣的高度就好，不用舉到胸口；用嘴巴吐氣，吐得太快就把嘴縫調小，讓時間拉長。深呼吸的用意是當放大鏡，動作做大一點，肌肉的變化才看得見。核心的口令只有一句：控制肌肉的比例少一點，看著它發生的比例多一點。意念發出的指令要輕到身體可以不服從，氣不夠了就讓它停在那裡，接受就好。

同一件事有三個切入點，由粗到細：

  • 第一個：手臂舉起、放下的大動作。用深呼吸把肌肉變化放大，先看見「原來有這回事」。
  • 第二個：手停在四十五度，既不是平舉也不是垂下，手肘不打直、肩膀自然鬆。吸氣時身體往後往上、吐氣時往前往下，只在這個微幅起伏裡讀肩部肌肉。
  • 第三個：完全不動，也不刻意深呼吸，就用一般呼吸去知道吐氣時肌肉仍有變化。這個最細。

升級版是在第三個切入點上再把意念調小：發現眉頭皺起來就鬆開，觀察範圍縮小，但仍保持一定程度的覺知。

四、拳架複習與如封似閉

本堂完整打了兩遍第一段，從起勢、攬雀尾、單鞭、提手上勢、白鶴亮翅、摟膝拗步、手揮琵琶一路到大搬攔棰。跟不上不用勉強，可以坐著用眼睛看、用呼吸跟著打，重點是抓到打拳時的意境，抓到了才有東西可以模仿。

進身跟步是本堂特別點出的環節。不要用後腳蹬起來，而是讓膝蓋持續往前送，重心自然往前，後腳就會變輕，這時候收腳、重心再拉回來即可。最簡單的練法就是站著往前往後，並且要維持步寬。

阿郎也點出把多餘動作拿掉之後，動作會變小、不需要用力，但絕對不是塌掉。

保持疏通為前提、為第一優先，然後再來調動作的大小。

新教的如封似閉在搬攔棰之後：放下來、扣進來、轉過來，重心往後走時手慢慢拉開放到腰間，再往前輕輕起來，坐掌收尾。手肘不超過肩線，收到腰間時不要張成雞翅，出去時肩膀不可以聳起來。阿郎另外說明更深一層的運作：手放下來不是把力量抽掉，而是另一邊的胯先收，肩膀跟著鬆，對角線自然帶出形狀。

五、四元素調一致

打拳時同時看四件事：動作、肌肉、呼吸、意念。動作慢一點，肌肉才不會爆發收縮；呼吸順暢，情緒就穩定；意念剛剛好，不多不少。四個調到一致，動作看起來就有那麼一回事。慢的極限可以推得很遠，慢到旁邊的人幾乎看不出你在動，但你自己知道它一直在動；只要一起「想用力」的念頭，力量就會跑出來。

這四個元素在如封似閉上走了三次：左手輕輕放下、肩膀一起鬆，右手扣進來並輕輕轉腰，扣到兩手臂平行後重心往後走，手慢慢拉開放到腰間，重心再往前、手輕輕起來，最後坐掌。阿郎說明，鬆到某個程度反而會覺察不到肌肉的變化，那不是退步，而是差異太小；意念從「牆」轉變成「蛋」，心不再那麼緊，定的狀態就會出來。

六、回家練習

  • 五點放鬆：肩膀 → 膻中穴 → 髖關節 → 膝蓋 → 湧泉穴，一次練一邊再換另一邊，最後用一口吐氣走完整條線；有餘力再試雙腳平行同時做
  • 感覺練習：三個切入點依序往細走，從舉手的大動作收到只用一般呼吸，並試著把意念調小
  • 站樁與坐姿：可以天天練，坐姿再放低一些；抬膝蓋的時間不要太長，怕不穩先扶著
  • 拳架：看課堂影片複習如封似閉，配合動作、肌肉、呼吸、意念四個元素慢慢走一遍
  • 心法：練的時候抓自己的邊界，在邊界上運行就好；覺得慢起來很卡，通常是意念還要再放鬆一點

2026-09-02｜主題：五點放鬆串起單腳站立，以四元素把如封似閉打慢

一、本堂主軸

這一堂的主軸是「把局部串成整體」。開場由學員提問帶出五點放鬆，阿郎順勢把它接回單腳站立的四個要素，說明為什麼上半身要靠一條吐氣的線鬆下來。中段回到感覺練習的基本功，練的是在吐氣時看見肌肉自己放下來，而不是用力把它壓下去。後半段完整打了兩遍第一段拳架，並在搬攔棰之後新教如封似閉。全堂反覆出現的判準只有兩條：先讓身體疏通，再談動作大小；先讓結構在，再談肌肉要鬆到哪裡。

二、五點放鬆：從肩膀到湧泉穴的一條線

五點指的是肩膀、膻中穴、髖關節、膝蓋、湧泉穴。阿郎說明這套練法的來由：一開始就要求全身均勻放鬆，對多數人來說切不進去，因為身體太大、沒有著力點，所以先給五個點做前面的串連。

操作方式是把手貼在點上，配合吸氣吐氣去感受手底下肌肉的變化。肩膀可以直接貼在肩關節附近；膻中穴可以壓著，也可以握拳放在正前方不接觸，感受吸氣時的膨脹與吐氣時的收縮；髖關節這一帶平常很難意識到，摸著去觀察比較大範圍的變化即可。膝蓋與湧泉穴摸不到，改用觀想：膝蓋在微彎狀態下先抓到腿部肌肉的感覺，再用意念定位；湧泉穴則想像那口氣從腳掌這個位置洩出去。

五個點都跑過一次之後，最後要用一口吐氣快速走完整條線，從肩膀、膻中穴、髖關節、膝蓋到湧泉穴，感受這個由上而下的流動。這樣上半身會往下鬆，下盤因為承重反而紮實，整條線串起來就成為支撐身體的支柱。

有學員問是否要兩邊一起做。阿郎回答最好是整體，雙腳平行站立時觀察範圍可以放大一些，但意念不要跟著擴太大，否則注意力過強反而失去放鬆；一開始難度會高一點，先一邊一邊練也可以。

另有學員問抬腳時是吸氣還是吐氣。阿郎說明自己的做法是在練沉起，沉一定配吐氣，起是第二順位，所以起來的時候仍是吐氣；只有當力量要直接往上、例如一個往上的攻擊動作，整體才會變成吸氣。

三、單腳站立的四個要素

阿郎在課中直接考大家單腳站立的四個要素，最後逐項補齊：

第一是三點一線。大拇指內側、膝蓋、髖關節從前面切過來時要落在同一個範圍內，膝蓋往外跑或往內跑都是錯位，容易翻車，腳也會受傷。

第二是腳掌與地面的接觸。腳跟是一個支撐，前腳掌後方那一排骨頭是另一個支撐，兩者都要吃到力，不能只有一點凸起、其他地方浮著。不均勻時踝關節的力量會集中在少數位置，很容易受傷；穿鞋時更難抓到與地面的平穩狀態。腳掌沒做好之前，會像站在圓木頭上一樣晃，把重量均勻分布進來，那個圓木的感覺才會散開。

第三是上半身的五點放鬆。上面重、只要一晃整體就不穩，所以要透過吐氣讓它呈現往下走的狀態。這也是為什麼要練坐姿——讓身體先知道整個鬆下來到底是什麼感覺，身體鬆了才能做更多事。

第四是腿力。腿力靠重訓與深蹲就會有；站樁比較容易調整到第二與第三項；三點一線則要在準備做單腳站立時就開始練，因為髖關節通常會往外，要把它收回來需要另外花時間。

針對個別學員，阿郎給的回饋是：坐姿要再放低一些，目前膝蓋周圍的穩定度看起來有進步，可以持續；也可以練抬膝蓋，但時間不要太久，怕不穩就先扶著。肩胛骨與上背的僵硬則要從腦袋的放鬆去調，那部分比較麻煩。

四、感覺練習的基本功：三個切入點

感覺練習從三次深呼吸開始。手舉到肋骨下緣的高度就好，不用舉到胸口；尾閭處稍微收一點肚子，不要讓腰折進去太多；吐氣用嘴巴，吐得太快就把嘴縫調小，把時間拉長，速度慢下來才看得到肌肉的變化。

深呼吸的用意是當放大鏡。動作小的時候看不到肌肉變化，做大一點才知道原來有這回事；等覺知練出來，才有能力看更小的東西。這一段練的不是動作，是「看到自己肌肉的變化」這件事本身。

控制肌肉的狀態讓他少一點點，然後看到肌肉變化發生的狀態讓他比例佔多一點點。

意念發出的指令也要輕。阿郎說明，那個指令必須是身體可以反抗的，允許它不做、允許它停在那裡；不要氣不夠了就急著把手壓下來，停在哪裡就接受它。

同一件事有三個切入點，由粗到細。第一個是手臂舉起放下的大動作。第二個是手停在四十五度，既不是平舉也不是垂下，手肘不打直、肩膀自然放鬆，吸氣時身體往後往上、吐氣時往前往下，只在這個微幅起伏裡看肩部肌肉的變化。第三個最細，不再轉動、也不刻意深呼吸，就用一般呼吸去知道吐氣時肌肉本身仍有變化。升級版是在第三個切入點上再把意念調小：發現眉頭皺起來就鬆開，觀察範圍縮小，但仍保持一定程度的資訊蒐集。

五、吐氣不要加壓：意念與力量的交替循環

有學員反映吐氣時肩膀與後背反而有緊縮感。阿郎回應這正好是相反的方向：用力吐的時候，肌肉確實會出現那種加壓的緊縮。正確的做法是吸飽氣之後自然而然讓它吐出來，不去加壓，胸腔自然下沉，肩膀就不會壓下去。

如果已經養成加壓的習慣，調整方式是兩邊交替。先用意念把吐氣的力量收少一點，等身體適應了，再把意念本身也放輕一點；接著又發現力量還可以再少，再把意念調得更輕。這樣循環下去，吐氣就會回到很自然的狀態，肌肉的變化也才看得清楚。阿郎補充，身體與腦袋是雙向的，能調多少就調多少，在邊際範圍上運作即可，但要保持那個「知道」，否則就只是放著不管。

阿郎也把基本功的定義說了一次：練到身體不用動腦都可以運行的，才叫基本功。這也是為什麼前面要花這麼多時間，把東西打進身體裡面去。

六、拳架複習：兩遍第一段與進身跟步的整體性

本堂完整打了兩遍第一段，從起勢的收肘、垂手、提腕、起手、伸指、屈臂、豎掌、伸手、沉手、合手，經攬雀尾、單鞭、提手上勢、白鶴亮翅、四個摟膝拗步與兩次手揮琵琶，一路到大搬攔棰的提掌揚拳、裡裹棰、直上撇身棰、外轉陷掤攔撲直上、搬攔棰。

阿郎說明跟不上不必勉強：可以坐著用眼睛看，假想是自己在打，只要維持呼吸順暢，看完也可以。要抓的不只是身體狀態，而是打拳時的意境；抓到了才有東西可以模仿，沒抓到就只剩動作。

第二遍後特別點出進身跟步。多數人會直接用後腳蹬起來，比較省力的做法是讓膝蓋、腿部持續往前送，重心一直往前，後腳自然就變輕，這時候順勢把它帶上來放好，重心再收回來。最簡單的練法就是站著往前往後，但不能只做腿部，要把五點放鬆的整體性帶進來：上身鬆、腿部鬆，膝蓋往前、後腳變輕，回來時胯先鬆一下，上半身又能繼續往後放鬆，循環起來像一個滾輪。也有學員問是否要維持步寬，阿郎的回答是當然要，沒有步寬做這個動作就會卡，自己試一次身體就會告訴你。

七、學員提問：白鶴亮翅、摟膝拗步與提手上勢的方向

學員問白鶴亮翅出現幾次。阿郎確認第一段的白鶴亮翅只有一次；接在後面的是摟膝拗步，第一段共有四個，順序是左、左、右、左。

關於提手上勢的方向，學員問身體要怎麼轉。阿郎說明那個四十五度其實是錯覺：先做完單邊、扣進來時，為了腳步好移動，轉個三十度大概就夠了，重心站上來之後接提手上勢、落步、手揮琵琶。從左摟膝拗步掌接進身跟步、回落半步時，腳步就已經在四十五度位置，站起來時面朝的方向跟著那隻腳走即可。

另一個常見毛病是手揮琵琶時手做太多。阿郎示範時指出，那隻手其實很安靜，只有放下，其餘都是身體帶過來的，看手肘與身體的關係最準；把拉的動作再減少一些，跟著身體走就好。他也提醒把多餘動作拿掉之後，動作會變小、不需要用力，但絕對不是塌掉，必須在疏通的狀態下維持。疏通是第一優先，動作大小是之後才調的事。

八、站樁作為下手點：結構在，放鬆的是肌肉

有學員說看影片跟著打卻找不到下手點。阿郎回應站樁本身就是下手點。站樁與打坐一樣，一開始都會有架子上的要求，重點是架子不能垮掉；在有架子的前提下，去看撐的力量能不能再少一點點，但形狀維持得住。

鬆掉的是肌肉，大部分的肌肉都是放鬆的狀態，少部分的肌肉在維持這個框架。結構要在，你要放鬆的是肌肉。

做到這個程度時，通常會開始出現拉筋的感覺，這是方向對了。再往下走，支撐的框架會變得非常明顯，這時候才進得到下一步：把框架換成有鬆的東西在裡頭，框架的外貌還在，但撐的感覺不見了。那不是往上頂，而是有東西往下、有東西往上的放鬆同時存在。阿郎說這一層很難用語言講，只能在有框架的情況下持續嘗試各種放鬆的可能性，摸索一陣子之後自然會轉過來。

課中也有學員轉述前輩談腰胯的說法：胯可以移動的距離其實很有限，動如春蠶抽絲，像海嘯的波浪，一開始很小、傳出去卻會變大；前提是要通，而且千萬不能用勁，一用勁腰就跟著用力。另一個比喻是一碗水要平，移動時要平，同時腳要站穩。

九、如封似閉：扭回轉環、進身雙按、坐掌

第一段最後剩下的就是如封似閉。整體路徑是：放下來、扣進來，扣的時候身體也跟著轉，手打開時重心往後走，把手放到腰間，再往前起、坐掌收尾。

外形上的要求有三點：手肘不會超過肩線，所以收的時候不是往外繞、而是直接收到腰間；不要張成雞翅；出去時肩膀不可以起來。收到腰間也不用收到底，到自己不勉強的位置就好。

阿郎接著講了更深一層的運作方式。手放下來不是單純把力量抽掉，它跟另外一邊的胯有關係：那一邊的胯往內收、像把小腹收起來那樣，肩膀就會鬆，這一側的空間變多、壓力變少，手自然就有那個形狀。搬的時候是這一邊的胯，攔的時候是另一邊的胯；接下來要做放下來的動作，又換回這一邊的胯收起來，往下帶動，並且連到對側的肩胛骨，路徑要怎麼放得看後背的肌肉。

他說明自己必須把兩個版本都講：最簡單的做法就是放下來、扣進來、轉過來、回來；但真正的運作路徑不只如此。只要記住任何動作都可以用腰胯來帶，就算忘記課堂上講過什麼，也能自己從腰胯出發去試。

我的經驗在變成你的經驗之前，你必須要有很多的練習，這是必然的。

十、四元素調一致與「慢」的練法

阿郎把打拳時要顧的東西收斂成四個元素：動作、肌肉、呼吸（連帶影響情緒）、意念。動作慢一點，肌肉才不會爆發收縮；呼吸順暢，內在情緒就穩定；意念剛剛好，不多不少。四個調到一致，動作看起來就有那麼一回事，即使自己不確定準不準，方向是對的。

課堂上照這四個元素慢走了三次如封似閉：左手輕輕放下、肩膀一起放鬆，右手扣進來、逆時針轉腰，扣到兩手臂平行後重心往後走、屁股放鬆，手慢慢拉開放到腰間，重心再往前、手輕輕起來，肩膀鬆、呼吸順暢、意念輕微，最後坐掌。

關於慢，阿郎舉了一個例子：有人可以慢到走過自動門而感測器偵測不到。真正的重點是，只要一起「想用力」的念頭，力量就會跑出來；放鬆讓肌肉自己慢慢動時，呼吸就知道它只動了那麼一點點。意念降低，身體給的訊息才收得到；意念太強，訊息就被蓋過去。他也說明，鬆到某個程度反而會覺察不到肌肉變化，因為差異太小，那不是退步，而是打到後來會覺得手腳好像不見了、像雲在飄的狀態；放鬆時手會刺刺麻麻，經歷幾次就知道那是正常的。意念從「牆」轉變成「蛋」，心就不會那麼緊，定的狀態自然會出來。

十一、回家練習與下次銜接

回家練習有四項。第一，單邊的五點放鬆，一次練一邊再換另一邊，感受左右的流動感，行有餘力再試雙腳平行同時做。第二，感覺練習的三個切入點，從舉手的大動作慢慢收到只用一般呼吸，並試著把意念調小，重點是看到吐氣時肌肉的變化。第三，站樁與坐姿可以天天練，坐姿再放低一些；抬膝蓋的時間不要太久，怕不穩先扶著。第四，看課堂影片複習如封似閉，配合動作、肌肉、呼吸、意念四個元素慢慢走一遍。

收尾時還有學員問：手放下來時重心會不會變。阿郎回答前七後三基本上不變，單純把肌肉狀態放掉時重心仍在前面；只有當支撐的力量往後走，重心才會移動，而且移重心時不是只放單邊，前面也要一起放，否則就像被拉著、動不起來。

下次會從如封似閉繼續往後銜接。練的時候記得抓自己的邊界，在邊界上運行就好；覺得慢起來很卡，通常是意念還要再放鬆一點。
