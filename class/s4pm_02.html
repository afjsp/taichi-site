第二堂課

2026.07.30
本堂內容

2026-07-30｜主題：找到「有東西沉、有東西起」的整體性——從單腳站立到左摟膝拗步掌

一、本堂核心

這一堂的重點不在動作多，而在「整體性」。上一堂練的是把多餘的力量放掉，這一堂把同樣的原則放進下半身：抬一隻腳的時候，另一隻腳要同時往下沉，兩件事像翹翹板一樣是一體的，而不是先站穩再抬腳。阿郎用閉眼扶牆的單腳提膝練習讓大家去抓這個感覺，最後再把它接到拳架上，完成白鶴亮翅到左摟膝拗步掌的一整段。

同一個原則也回到走路：重心要先落在後腳、那隻腳穩了才移重心，腳步輕、呼吸順，而不是一腳踏出去人就跟著倒過去。

二、走路：把放鬆帶到生活裡

有學員把外面推拿的阿偉教的走路方式拿來問，兩邊說法不同（一邊要腳跟先落地，一邊是腳掌先碰、慢慢放到底），阿郎說明兩者其實在講同一件事，只是前提不同：真正共通的是「這隻腳穩了才挪重心」，不要讓腳跟去撞地板，撞地板就會一直傷腳踝。

阿郎自己給的日常版標準很簡單，也比較容易帶到生活裡：收下巴、不看地板也不抬頭、一般速度走、腳步要輕、呼吸順暢。等這些做順了，再慢慢往上加膝蓋微彎不打直、收小腹與折胯的髖關節調整、肩膀自然擺動放鬆。

我們一次就是加我們能照顧到的分量就好，要不然你就是越加越多，心都不平靜的情況之下，你怎麼可能把它變成自然。

三、暖身複習：肩膀畫圓，腋下留一顆空氣球

進入腳的練習之前，先把上一堂的肩膀感覺練習複習一次。關鍵是手不要舉太高——舉太高這一塊會繃住，反而什麼都感覺不到；高度要落在相對比較不費力的位置，在那裡吸氣起、吐氣往前往下，去看吸與吐之間肩膀的差別有多大。

由此帶出一個貫穿太極的要求：腋下要留空間，像有一顆空氣球，不能夾。手臂貼著身體就是沒有空氣球的狀態。最細的版本是完全不轉動，只單純吸氣吐氣，還能看見肩膀的差異。

四、單腳站立的四個條件與翹翹板覺察

單腳站立要成立，有四個條件：三點一線（大拇指、膝蓋、髖關節從正面看成一直線）、腳掌與地面均勻接觸（不要翹起來）、上半身放鬆（上面重就容易失去平衡）、腿力。站的時候不是往旁邊找平衡，而是折胯往後坐，感覺像是「坐在自己這隻腳上」，屁股不外翹、脊椎打直。

接著做閉眼扶牆的提膝練習，兩人一組互相照看安全。閉眼是為了把最強勢的視覺關掉，其他感知才會打開。練的目標不是腳抬多高，而是抓到翹翹板的感覺：支撐腳往下沉的同時，另一隻腳自然被帶起來，兩件事同時發生。抓不到就抓不到，先做到腳跟輕輕離地、腳尖還在地板也算有練到。

膝蓋抖動代表腿力還不夠，這時候不要硬練單腳，改練雙腳起蹲去補腿力；練錯方向只會增加傷害。另外「勾腳」（腳跟往後勾）會多用小腿力量，單純抬膝蓋則是往前起、比較鬆，兩者感受可以自己比較看看。

五、拳架複習：白鶴亮翅接到左摟膝拗步掌

上一堂做到白鶴亮翅、順轉捛合、抱合就停住，這一堂把後半段接上去。完整順序是：右腳外轉45度→重心移右腳、左腳提起往前輕放→白鶴亮翅→順轉捛合、身面轉向後腳→抱合→左手往下壓、右手盪手直上到耳朵→提膝、放膝→重心過中、右手慢慢放平、身面轉正→手腕放鬆坐掌，完成左摟膝拗步掌，最後向前收式。

阿郎特別提醒：這一段裡身面只有兩個，一個對準後腳（右腳）、一個對準前腳（左腳）；過中之前重心一直在後腳，要先移動才會有「過中」這件事。盪手的手肘不要往上跑，腋下要留一顆空氣球的空間，不要夾。過中轉正那一段像飛機降落，右手是慢慢放平，不是抬起來。

定式的練習也在這堂被單獨拉出來：先擺好姿勢（前七後三、步寬要夠、身面對準、美人手不刻意折腕、收下巴、收小腹），維持不動，再靠呼吸一層一層把肩膀、手腕的僵化調鬆。定式不是擺出來就沒事，看起來不動，裡面要是有彈性的。

六、回家練習

  • 走路：先只做兩件事——觀察呼吸、讓腳步變輕。這兩樣穩了再加膝蓋不打直、收小腹，一次只加一項。
  • 扶牆提膝：閉眼、吐一口氣讓上半身鬆下來，再去感受支撐腳往下沉、另一腳被帶起來的同時性。腳不必抬高，膝蓋會抖就先停。
  • 回去留意哪一邊比較容易痠，下次可以直接回報。
  • 拳架：可以先拆成手的部分（盪手）與腳的部分（提膝放膝）分開練，熟了再合起來；覺得膝蓋已經有點負擔就休息，不要練過頭。
  • 課前課後各留意一次自己的狀態，下課時挑一個今天想帶走的東西，至少到睡前還記得它。

七、下次課程

下週四下午班停課（週三晚間班則是本週停），確切公告以群組為準。

2026-07-30｜主題：找到「有東西沉、有東西起」的整體性——從單腳站立到左摟膝拗步掌

一、這堂課真正要練的是什麼

上一堂的主軸是「把多餘的力量放掉」，這一堂在同一條線上往下走一格：重點不是把動作學會，而是要能看到身體的「整體性」——當一隻腳往下沉的時候，另一隻腳是被帶起來的，兩件事是同時發生的一件事，而不是兩個先後動作。

阿郎用翹翹板來比喻：一根板子、中間一個支點，一邊下去另一邊自然就起來，之所以會這樣，是因為它本來就是一體的。身體要找的就是這個狀態。所以這堂課從走路開始，經過單腳站立的四個條件、閉眼扶牆的提膝練習，最後才把它接進拳架的白鶴亮翅到左摟膝拗步掌。

課末有學員自己總結出這一堂的重點——「重點是在整體，所以翹翹板就很重要」——那正是阿郎這堂想讓大家帶走的東西。

二、走路：兩套說法，同一件事

課堂前段有學員拿外面推拿的阿偉所教的走路方式來問：阿偉要求腳跟先落地、重心在後、穩了以後重心再到前面，而且要走得非常慢；阿郎先前教的卻是不要用腳跟直接著地。學員被兩種說法卡住，不知道該聽哪一個。

阿郎的回應是：兩個都是在說同一件事，但做法不同，因為前提不同。真正共通的那一句是——這隻腳要先穩，才移重心。腳跟先落或腳掌先碰只是入口不同：阿偉的角度是慢放時腳跟比較容易放穩，而阿郎當初講「不要用腳跟撞地板」，是因為初學者常常重心一送就直接把腳跟砸下去，一直撞就會越走越偏、也會傷到腳踝；反過來如果腳尖先著地卻沒有放穩就壓上去，腳踝會一直晃、一直變形，那也是傷。

前提不同，做法就不同，所以我一次不會用兩種模式，因為它的概念是不同。

阿郎給的實作建議是：兩種都先練、都留一些記憶點；被阿偉調整完、腳的狀態最好的當下，就在旁邊多練幾次再離開，把那個感覺記起來。有疑問時直接當面問對方「這樣做的好處是什麼、真的會歪的話會怎樣」，問清楚了才會知道什麼時候該選哪一邊。

三、阿郎的日常走路版本：一次只加一項

阿郎自己這一套是刻意做得「比較淡」的，目的是能帶到生活裡，而不是只能在教室或家裡練。他的要求依序是：

  • 第一層：收下巴，不低頭看地板也不抬頭，用一般速度走，腳步要輕，呼吸順暢。手不要變成機器人，就是自然擺動，順便讓肩膀在走的過程中放鬆。
  • 第二層：等腳踝不會晃、呼吸也順了，再把膝蓋微彎不打直帶進來。
  • 第三層：再加髖關節的調整，也就是折胯與收小腹，這會連動到腰椎與尾椎。
  • 第四層：最後才回頭檢查肩膀是不是太用力。
我們一次就是加我們能照顧到的分量就好，要不然你就是越加越多，心都不平靜的情況之下，你怎麼可能把它變成自然。

有學員反映這樣走在路上很像怪人。阿郎的回應是不必把慢動作搬到馬路上——課堂上要求的慢是為了讓覺察長出來，帶到生活的版本只要腳步輕、呼吸自然、膝蓋不打直就夠了。這也是為什麼阿郎說他的嚴格不在單一動作上，而在「一直堆疊」：每一項都很輕，全部疊起來就很重，請大家挑自己撿得起來的先用。

四、身體調整的外求與自主

延續走路的討論，有學員提到自己對推拿、艾灸、氣功這類外部調整已經產生心理依賴，沒去做就覺得氣塞著、整天想睡。阿郎補充了一個觀察：針灸、拔罐、刮痧這類方法在它們自己的理論架構下，都屬於帶破壞性的處理——有刺激就會有增生，常做的話效益會遞減，於是只能越做越重。

所以他的態度不是不能用，而是使用時要保持一定程度的時間間隔，並且要重新認識這個方法跟自己的對等關係是什麼。

這個不是說交給人家就沒事了，交給人家通常會有很多事。

同一段裡也談到坐姿：不論坐硬墊、軟墊還是椅子，只要壓迫到尾椎，就是還要再調整；坐骨是拿來支撐的，重量要落在坐骨上而不是壓在尾椎上。這個原則後面在講單腳「像坐在自己這隻腳上」時又會用到。

五、上半身複習：肩膀覺察與腋下的空氣球

進入正式練習前，阿郎先複習上一堂的肩膀畫圓。要點是手不能舉太高——舉高的時候這一塊會繃住，反而什麼都感覺不到；高度要落在「相對力量比較少」的位置，在那個高度上吸氣起、吐氣往前往下，去看吸與吐之間肩膀的差異有多大。

阿郎現場修正一位學員把手往前舉得太高，說明起手時力量不該全集中在一處：

你在這邊全部都舉起來的時候，這邊已經死掉了，就沒有感覺了。

由此帶出一個貫穿太極的觀念——腋下要留空間，像有一顆空氣球，不能夾。手臂貼著身體就是反方向、沒有空氣球的狀態。這個空間要求在後面盪手時會再被提一次。

左右畫圓與前後起落哪個好，因人而異：左右版本會多一個延展或緊繃的位置，如果那個緊繃反而干擾了覺察，就用讓自己容易觀察的那一種。最細緻的版本是完全不轉動，只單純吸氣吐氣，還能看到肩膀的差異——那才是最細的。

六、單腳站立的四個條件

進到本堂主練習之前，阿郎把單腳站立的成立條件重講一次：

  • 三點一線：支撐腳的大拇指、膝蓋、髖關節，從正面看要能連成一條線。這是架構性的要求，不習慣單腳的人常常會把平衡拿到外側去，架構就跑掉了。
  • 腳掌與地面均勻接觸：腳掌翹起來會增加難度，平衡時很容易歪掉。
  • 上半身放鬆：上面重，重心就下不去，站起來一定不穩。
  • 腿力：腿力是靠平常折胯、雙腳起蹲練出來的，練久了自然站得穩、膝蓋不會晃。

平衡的方向也要修正：抬腳時身體不是往側邊找平衡，而是往後——在支撐腳上折胯、坐下去，讓三點一線成立。阿郎形容那個感覺是「雖然你是站著，但狀態像是坐下來，坐在你這隻腳上頭」；屁股不往外翹，從側邊看是往後坐，上半身幾乎跟坐在椅子上一樣，只是要讓脊椎打直，把直的力量順暢傳到腳的架構上，上半身才鬆得掉。

至於開胯的蹲姿練習，目的是把膝蓋撐開到腳的正上方——有些人站姿膝蓋會一直往內折，架構就跑掉了，要用蹲姿去把胯撐開。

七、閉眼扶牆的提膝練習

正式練習是兩人一組、靠牆、閉眼做單腳提膝，同組另一人用一根手指輕輕碰著確保安全。之所以要閉眼，是因為眼睛是最容易接收外界訊息的器官，大腦大部分時間都在處理視覺；把視覺關掉，其他感知才會打開，細緻度與敏感度會多出一截。

練習的目標不是抬多高。阿郎講得很清楚：要觀察的是什麼東西沉下去、另外一邊的東西如何起來。即使腳沒有真的離地，只是腳跟輕輕起、腳尖還在地板上，只要有沉有起，就算有練到。

抓不到怎麼辦？抓不到就抓不到。

現場學員回饋出好幾個不同的切入點：有人發現要很鬆才能平衡；有人發現動作必須慢，越慢越抓得到；有人是吐氣時腳才起得來，感覺特別輕，而支撐腳明顯變重——阿郎說那是另一種動態平衡；也有人只覺得痠，阿郎回應痠也是身體反應開始被發現的入口，回去可以留意是哪一邊容易痠。

有學員問「沉」跟「起」到底是同時還是先後。阿郎確認必須同時：如果先把重心擺好、站穩了再抬腳，那就拆成兩個動作，翹翹板就不見了。這比較難，不見得每個人當下都抓得到。

阿郎也提醒了一個前提：閉眼做這件事，心要有一定程度的安定；心浮躁、急著想做完，那個翹翹板一定會不見。所以先檢查心安不安定，不安定的話就先什麼都不做，讓心安下來再抬腳。

安全上的提醒是：膝蓋在抖、晃動的時候就是腿力不足，硬練會傷膝蓋。這時候要練的方向不是單腳站立，而是雙腳起蹲去補第四項的腿力——練錯方向只會增加傷害。

另外阿郎示範了「勾腳」與「不勾腳」的差別：腳跟往後勾時，小腿與膝蓋要多出一份力量；把那份力量放掉，就變成單純往前抬膝蓋，用比較少的力就能帶出鬆膝蓋的效果。兩者可以自己比較看看感受差在哪。

八、拳架：白鶴亮翅接到左摟膝拗步掌

上一堂只做到白鶴亮翅、順轉捛合、抱合。這一堂把後半段接上，而且難度提高——不只是提膝放膝，還要同時做一手下壓、一手盪手，三個動作綁在一起。

完整順序是：

  1. 右腳外轉45度，重心移到右腳，左腳提起往前輕放（留步寬），身面先對準左腳，做白鶴亮翅。
  2. 順轉捛合：右手慢慢放下、身體往順時鐘方向轉，左手慢慢起來，身面轉到對準後腳（右腳）時剛好做到抱合。這一段要收一點肚子，讓腰椎、尾椎與背部脊椎盡量是直的。
  3. 左手往下壓到小腹前方，右手做盪手直上到耳朵旁。盪手其實只有小小的一圈。
  4. 提膝、放膝。
  5. 重心往前移到中間，右手慢慢放平到接近水平，過中之後身面轉正對準前腳。
  6. 最後手腕放鬆坐掌，另一手掌面略朝地面做保護，完成左摟膝拗步掌，再向前收式。

阿郎拆成三段練：先練第一段（到抱合），再加第二段（盪手＋提膝放膝），最後加第三段（過中轉正），三段都熟了再連起來。若擔心三個動作一起做不上來，可以先把手做完再抬腳。

現場修正的重點包括：

  • 盪手時手肘不要往上跑，直接過來就好；腋下一樣要有空間，不要夾。
  • 過中那一段右手是慢慢放平，像飛機降落後滑行煞車，不是抬起來。
  • 最後是「手腕放鬆」坐掌，不是把肌肉拉起來。
  • 這一整段只有兩個身面：一個對準後腳（右腳）、一個對準前腳（左腳）。過中之前重心一直在後腳，一定要先移動才會有「過中」。
  • 手當然可以只用手做，但真正要的是折一些胯、用身體來帶：肩膀先鬆掉，一整片肩膀鬆著把手盪起來，那就不只是手，而是整個身體。

九、定式：看起來不動，裡面要有彈性

這堂課單獨拉出一段練定式——先把左摟膝拗步掌的姿勢擺好並維持不動：前七後三、步寬要夠（步寬是左右不是前後）、身面對準、手的高度大致在肩膀、手腕不刻意折出皺褶（美人手）、收下巴、眼睛看前方、呼吸自然、兩腳掌都與地面均勻接觸。

擺好之後不是就沒事了。阿郎逐一調整每位學員的角度、步寬與手的高度，同時帶著大家在定式裡持續吸氣吐氣，一層一層把肩膀、手腕的僵化調鬆。他特別說明「放鬆」的定義：

放鬆不是放掉，是把肌肉僵化的部分讓它變得比較靈活一點。

檢查方法是做一個「要動不動」的測試：在那個姿勢裡稍微試著動一下，就知道這隻手、這個肩膀、腳踝、膝蓋是不是好動的。可以做一個動態掃描，讓整個架構在外表看不出動作的情況下，內在肌肉仍保有彈性。這樣等一下真的要動——不論往前往後——流暢感才帶得進來；如果是僵化的，就得在某個動作上額外刻意多做一份力。

有學員問「每一次微調是不是要找到最不用力的那個」。阿郎的回答是先做到不僵化就好；至於用不用力，那牽涉到整體性，要能用肩膀帶動作、用軸心帶動作，那需要先有一定程度的鬆與平衡，整體性的微調才會自然發生。

另一個問題是「動作是不是不可以不舒服」。阿郎說不見得——像這個拳架在胯的地方本來就是扭動的，會有一點不舒服很正常。要做的是先把不舒服減到最少，然後在這個比較不舒服的姿勢裡仍然找得到暢通；不是硬逼過去，因為逼過去很可能只是把自己固定在錯的位置上。不確定的時候就找阿郎核對。

十、回家練習與下次銜接

  • 走路：先只做觀察呼吸、讓腳步變輕這兩件事，穩了再依序加膝蓋不打直、收小腹與折胯、肩膀放鬆，一次只加一項。
  • 扶牆提膝：閉眼、先吐一口氣讓上半身鬆下來，再去感受支撐腳下沉與另一腳被帶起的同時性。腳不必抬高，膝蓋會抖就改練雙腳起蹲補腿力。
  • 回去留意單腳練習時是哪一邊比較容易痠，下次可以直接提出來。
  • 拳架：可以先分開練手（左手下壓＋右手盪手）與腳（提膝放膝），熟了再合起來，最後才嘗試三個動作同時。膝蓋覺得有負擔就休息，不要練過頭。
  • 阿郎這一期新增的要求：進教室時先留意自己現在是什麼狀態，下課時挑一個今天最有感覺的東西帶走，並確保至少到睡前還記得它、還能練一小段。不論這一週有沒有回去練習都一樣做這件事。
  • 下次課程：下週四下午班停課（週三晚間班則是本週停），確切公告以群組為準。復課後會接續把過中轉這一段拆得更細來練。
